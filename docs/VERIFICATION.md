## Numerical oracles

- 0.5 kg whole broccoli at 5 °C: **192–216 mL CO2/pack/day**.
- 0.06 m², RQ 1, 5% internal O2 at 1 atm: **20,000–22,500 mL/m²/day/atm O2 permeance**.
- Same geometry and 8% internal CO2: approximately **40,201.005–45,226.131 mL/m²/day/atm CO2 permeance**.
- A 20 °C stage instead uses the cited 140–160 mL CO2/kg/hour interval: **1,680–1,920 mL CO2/pack/day** and **175,000–200,000 O2 permeance** at that stage.
- Illustrative 2 g water allowance / 0.06 m² / 30 days: **1.1111 g/m²/day maximum WVTR**.
- Illustrative (12 − 3) mL oxygen / 0.06 m² / 30 days / 0.21 atm: **23.8095 mL/m²/day/atm maximum O2 permeance**.
- Twelve extra travel hours in the dry example tighten these to approximately **1.0929** and **23.4192**, respectively. UI rounding shows 1.09 and 23.42.
- Initial oxygen above the total allowance is **infeasible under the budget**; the engine never emits a negative acceptable permeability.

These are implementation test fixtures and calculations. The dry-food tolerances are not measured thresholds for commercial peanuts or chips. The fresh requirement is not a measurement of a manufactured film.

## Reproduction commands

From the repository root with the prepared virtual environment:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check backend tests scripts/repo_audit.py
.\.venv\Scripts\python.exe -m ruff format --check backend tests scripts/repo_audit.py
.\.venv\Scripts\python.exe -m pip check
```

With the local server running, from `frontend`:

```powershell
pnpm run format:check
pnpm run build
pnpm run test:e2e
pnpm audit --prod
```

Test artifacts are intentionally local: `tmp/screenshots`, `tmp/exports` and `tmp/browser-results`. Browser traces may contain the test inputs and are not uploaded. Failure artifacts are regenerated by Playwright; the committed test source is the reproducible evidence path.

## Known verification boundaries

The real microphone/provider path requires user permission and speech-service availability; typed fallback and absence-of-API behavior are tested. No real farmer field study, packaging lab experiment, sensory trial, microbial challenge study, converter qualification or external food expert sign-off has been performed. No public deployment, device Safari test or multi-user security validation is claimed.

The Starlette test client currently emits a deprecation notice about using httpx rather than httpx2. Tests pass; this is visible and not suppressed. The runtime API does not depend on the test client.
