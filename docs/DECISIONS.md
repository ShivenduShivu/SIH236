# Decision log

## D001 — Engine before interface (2026-09-29)
The user needs a defensible system without a supplied training set. Use a deterministic, evidence-backed engineering engine with explicit gaps. Training a reliable food-specific shelf-life predictor in ten hours is not justified. Any AI input aid must be removable without changing the science.

## D002 — Local prototype and privacy
No deployment is authorized. Serve on loopback, keep provider keys off the client, save scenarios only in the user's browser, and expose explicit export/delete. Avoid sensitive farmer identifiers and precise location requirements.

## D003 — Scientific conservatism
Use literature reference ranges with source and applicable conditions. RQ, chosen atmosphere targets and toy transfer coefficients are assumptions/fixtures, not measured catalogue properties. No complete supplier match is claimed without all relevant condition-matched evidence. No expiry date, safety percentage or food-waste reduction claim.

## D004 — Navigation and feasibility
Use the approved spacious visual direction and an optional orbit menu. Always retain a visible trigger and keyboard/touch alternative. Journey timing is core scope; live maps/traffic, route optimization and logistics integrations are deferred.

## D005 — Documentation status
Research PDF authoring was cancelled before content creation. Existing design PDFs/images remain local ignored reference artifacts. Preserve the user's technical PDF brief and create real code/test evidence first.
