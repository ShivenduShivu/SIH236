# Evidence register

Research checked 29 September 2026. This is a source register, not a claim that datasets were downloaded, licensed or independently validated. Source facts and calculations must remain distinct. Original papers and supplier certificates take precedence over generic resin tables.

| ID | Resource | Intended use and limits |
|---|---|---|
| UCD-BROCCOLI | [UC Davis broccoli facts](https://postharvest.ucdavis.edu/produce-facts-sheets/broccoli) | Whole-head respiration at 5 C: 16–18 mL CO2/kg/h; at 20 C: 140–160. Cut product differs. Educational citation; review reuse terms for commercial distribution. |
| USDA-AH66 | [USDA Commercial Storage handbook](https://www.ars.usda.gov/is/np/CommercialStorage/CommercialStorage.pdf) | Commodity-specific storage context, not a universal shelf-life guarantee. |
| FAO-PACK | [FAO packaging and handling](https://www.fao.org/4/y4358e/y4358e05.htm) | Ventilation, handling and mechanical protection. |
| FSSAI-2025 | [Packaging compendium, April 2025](https://fssai.gov.in/upload/uploadfiles/files/Compendium_Packaging_V_%2002-04-2025.pdf) | Food-contact suitability and evidence; does not certify this software or a named resin for every use. |
| FSSAI-NOTICES | [Current notifications](https://www.fssai.gov.in/notifications.php) | Check later amendments, scope and effective dates separately. 2025 compendium is not assumed complete for 2026. |
| JINDAL-18MM388 | [Metallyte 18MM388 supplier sheet](https://jindalfilms.com/wp-content/uploads/jindal-products/productpdf/Metallyte_18MM388_177.pdf) | Historical 2013 sheet: 18 um metallized BOPP; OTR 26 cm3/m2/day at 23 C/0% RH; WVTR 0.20 g/m2/day at 38 C/90% RH with method footnotes. Typical grade data, not a full laminate or current quote. Pressure basis must be verified. |
| ASTM-D3985 | [ASTM D3985-24 public scope](https://store.astm.org/d3985-24.html) | Oxygen transmission terminology. Full standard not purchased or reproduced; do not claim compliance from this reference. |
| ASTM-F1249 | [ASTM F1249-25 public scope](https://store.astm.org/f1249-25.html) | Water-vapor transmission terminology and test conditions. |
| FDA-AW | [FDA water activity guide](https://www.fda.gov/inspections-compliance-enforcement-and-criminal-investigations/inspection-technical-guides/water-activity-aw-foods) | Definition: water activity is not moisture percentage. Historical scientific reference, not Indian regulatory advice. |
| YEH-2026 | [Yeh and Turan, npj Science of Food (2026)](https://www.nature.com/articles/s41538-026-00741-7) | Related clustering work; limited permeability data and preprocessing ambiguities need original-source reconstruction. Clustering quality is not recommendation accuracy. |
| TRANSMAT-2021 | [TRANSMAT dataset paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC8144675/) | Expert annotated literature extraction, not commodity-package outcome labels. Dataset not yet integrated. |
| SMARTPACK | [SmartPack-Finder repository](https://github.com/whps0620/SmartPack-Finder) | Related public demo, reference only; license/provenance not verified for copying. |
| IVV | [Fraunhofer digital shelf-life tools](https://www.ivv.fraunhofer.de/en/packaging/digital-tools-for-shelf-life-prediction.html) | Precedent for linking experimental data to physical models. Their validation does not validate this prototype. |
| MAPOPT | [INRAE MapOpt](https://plasticnet.transform.inrae.fr/IateTools/InfoMapOpt) | Related MAP decision-support approach; product domain differs. |
| MAP-APPLE | [Annurca apple respiration/MAP model, IJFST (2009)](https://academic.oup.com/ijfst/article/44/5/890/7865181) | Mass-balance precedent; coefficients are product- and condition-specific. |
| RECYCLASS | [Design-for-recycling guidelines](https://recyclass.eu/protocols-guidelines/design-for-recycling-guidelines/packaging/) | Material design guidance; not proof of collection/recycling in an Indian locality or an LCA. |
| FASTAPI | [FastAPI documentation](https://fastapi.tiangolo.com/) | API and static frontend architecture. |
| PYDANTIC | [Pydantic strict mode](https://docs.pydantic.dev/latest/concepts/strict_mode/) | Type validation does not establish scientific correctness. |
| RENDER | [Render FastAPI guide](https://render.com/docs/deploy-fastapi), [free service limits](https://render.com/docs/free) | Future deployment only; free services sleep and have ephemeral local storage. |
| W3C | [Hover/focus content](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html), [keyboard](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html) | Orbit menu must have persistent, dismissible keyboard/touch alternatives. |
| OWASP | [Prompt injection prevention](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html) | Future AI extraction should treat transcripts/documents as untrusted data and have no privileged actions. |
